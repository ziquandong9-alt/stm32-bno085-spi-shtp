# Port 架构与支持范围

| 组件 | 状态 | 说明 |
|---|---|---|
| 协议核心 | 已支持 | ISO C99，不包含 STM32 头文件 |
| STM32F4 HAL SPI/DMA | 已实机验证 | 仓库包含完整示例工程 |
| 函数表 Port | 已支持 | 与 SDK 无关的适配边界 |
| Port 模板 | 已支持 | 编译期 TODO 防护，避免误用空实现 |
| Keil MDK | 已实机验证 | STM32F407ZG 目标工程 |
| CMake + GCC/Clang | CI/主机测试 | 库、测试以及安装/导出目标 |
| STM32CubeIDE | 已说明导入方法 | 使用仓库内 `.ioc` 生成或导入工程 |
| FreeRTOS | 参考示例 | 任务通知和长度为 1 的覆盖队列 |
| I2C/SHTP | 尚未实现 | 需要单独处理传输长度和时序约束 |
| UART-RVC | 尚未实现 | 固定帧协议不同，应作为独立后端 |
| 多实例 | 规划中的破坏性改造 | 需要把全部静态状态迁移到句柄中 |

移植到新 MCU 时，如果目标 SDK 能提供全双工异步 SPI，优先使用函数表 Port；
若需要直接控制 IRQ/DMA 或追求最小开销，则实现专用的编译型 Port。

不要在中断内用长时间阻塞 SPI 去模拟异步回调。如果目标 SDK 没有异步 SPI，
请保留阻塞式 `BNO085_Poll()` 路径，或在 Port 层增加工作任务。
